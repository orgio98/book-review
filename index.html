전체 서재 JSON 백업

등록된 모든 책 정보, 발췌 문장, 여백 메모, 태그, 양방향 상호 참조 데이터를 하나의 JSON 파일로 안전하게 내려받습니다.

JSON 백업 파일에서 복원

아이폰 · 아이패드 자동 동기화 (GitHub Gist)

내 GitHub 계정의 비공개(secret) Gist 하나에 서재를 저장해 두고, 앱을 열 때와 내용을 바꿀 때마다 자동으로 맞춥니다. 같은 토큰을 각 기기에 한 번씩 넣으면 같은 Gist를 찾아 연결합니다.

  1. GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token
  2. 권한은 gist 하나만 체크하고 토큰을 만든 뒤 복사합니다.
  3. 아래 칸에 붙여 넣고 [연결하고 동기화]를 누릅니다. 다른 기기에서도 같은 토큰으로 반복합니다.

동기화 꺼짐

  • 한 기기에서 지운 책과 문장은 다른 기기에서도 지워집니다. [전체 데이터 삭제]와 [샘플 서재로 초기화]도 마찬가지이니, 실행 전에 JSON 백업을 받아 두세요.
  • 같은 문장을 두 기기에서 따로 고치면 나중에 고친 쪽이 남습니다.
  • 토큰은 이 기기 브라우저에만 저장됩니다. GitHub 저장소 코드에는 넣지 마세요.
  • 비공개 Gist는 목록에 보이지 않지만, 주소를 아는 사람은 열어 볼 수 있습니다.

홈 화면 아이콘

사진 앨범의 이미지를 골라 홈 화면 아이콘으로 씁니다. 아이콘은 [홈 화면에 추가]를 하는 순간에 정해지므로, 저장한 뒤 Safari의 공유 버튼 → [홈 화면에 추가]를 다시 해 주세요.

이미지를 끌어 위치를 맞추고, 아래 막대로 확대하세요. 보이는 그대로 아이콘이 됩니다.

  • 여기서 저장한 아이콘은 이 기기에만 적용됩니다. 아이패드에서도 같은 방법으로 한 번 더 해 주세요.
  • 모든 기기에 한 번에 적용하려면 [PNG 파일로 내려받기]로 받은 apple-touch-icon.png를 GitHub 저장소의 index.html 옆에 올리면 됩니다.
  • 이미 홈 화면에 추가해 둔 아이콘은 바뀌지 않습니다. 기존 것을 지우고 다시 추가해야 하는데, 지우기 전에 동기화가 끝났는지(또는 JSON 백업을 받았는지) 꼭 확인하세요.
